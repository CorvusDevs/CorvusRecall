Help desk

Support without a maze.

Contact

Email corvusdevs@outlook.com. Include the app version, device model, system version, and what you expected to happen. Settings can prepare a message with version details.

Start a library

Create a deck in Library, open it, and add a front and back. You can add images, audio, hints, sources, tags, and specialized card types later.

Import cards

Use Settings, Import, Export, and Backups for CSV or Anki-compatible text. Corvus Recall shows a mapping or preview before saving. For documents and images, open Document Drafts and review every extracted card before adding it.

Back up or move a library

Create a Native Backup for the most complete portable copy. Corvus Recall validates media and library structure before replacing data. A safety snapshot is retained before restore. Optional iCloud backup and sync remain off until you enable them.

Permissions

Photos, microphone, notifications, and local network access are requested only when the corresponding feature needs them. If you previously denied access, open System Settings or the Settings app, find Corvus Recall, and change the permission there.

Widget or Share is missing

After installing Corvus Recall, open it once. To add a widget, edit the Home Screen and search for Corvus Recall. To save selected text or a web address, open the system Share sheet and choose Save to Corvus Recall. Use Edit Actions if it is not visible.

Recover from a problem

If the library cannot open safely, Corvus Recall presents Recovery Center instead of silently replacing it. Try the preserved-file and snapshot options first. Contact support before deleting data if the material is important.

Privacy and deletion

Read the privacy policy. Delete All Data removes the local library and history but cannot remove exports saved elsewhere or documents stored in iCloud Drive.
