Mesa de ayuda

Soporte sin laberintos.

Contacto

Escribe a corvusdevs@outlook.com. Incluye la versión de la app, el modelo de dispositivo, la versión del sistema y qué esperabas que ocurriera.

Crear una biblioteca

Crea un mazo en Biblioteca, ábrelo y añade anverso y reverso. Después puedes agregar imágenes, audio, pistas, fuentes, etiquetas y tipos especializados.

Importar tarjetas

Usa Ajustes, Importar, exportar y respaldos para CSV o texto compatible con Anki. Corvus Recall muestra una asignación o vista previa antes de guardar.

Copiar o mover la biblioteca

Crea una copia nativa para conservar el contenido completo. Corvus Recall valida archivos y estructura antes de reemplazar datos y conserva un punto de seguridad antes de restaurar.

Permisos

Fotos, micrófono, notificaciones y red local se solicitan solo al usar la función correspondiente. Si rechazaste un permiso, abre Ajustes del sistema o la app Ajustes, busca Corvus Recall y cámbialo allí.

No aparece el widget o Compartir

Abre Corvus Recall una vez después de instalar. Para el widget, edita la pantalla de inicio y busca Corvus Recall. Para guardar texto o un enlace, abre Compartir y elige Guardar en Corvus Recall.

Recuperarse de un problema

Si la biblioteca no puede abrirse de forma segura, Corvus Recall presenta el Centro de recuperación. Prueba primero el archivo preservado y los puntos de recuperación.

Privacidad y eliminación

Consulta la política de privacidad. Eliminar todos los datos borra la biblioteca local, pero no elimina exportaciones o documentos de iCloud Drive.
